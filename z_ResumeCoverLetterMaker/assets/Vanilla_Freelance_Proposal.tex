\section{How I Approach Freelance Engagements}

I treat every project as if it were my own product. My working process is structured to minimize back-and-forth and maximize delivery confidence:

\begin{itemize}[leftmargin=0.3in, noitemsep, topsep=2pt, partopsep=0pt, parsep=1pt]
    \item \textbf{Discovery first:} I start by understanding your business problem, existing stack, and non-functional requirements (latency targets, scalability, uptime SLAs) before writing a single line of code.
    \item \textbf{Incremental delivery:} I break work into small, reviewable milestones. You see progress early, and we can course-correct without waste.
    \item \textbf{Async-friendly communication:} I provide clear written updates, commit messages, and documentation so you are never blocked waiting for a sync.
    \item \textbf{Handoff-ready code:} I write code that your team can maintain after I'm gone -- with tests, documentation, and clean architecture rather than clever hacks.
    \item \textbf{Timezone flexibility:} I'm based in India (IST) and can accommodate overlap windows with U.S. / EU teams for live syncs.
\end{itemize}
